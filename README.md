# DoQuietly 🤫

**DoQuietly** is a lightweight, clean Windows utility built to keep your workspace tidy by hiding specified applications directly from the taskbar. 

![DoQuietly GUI]

## ✨ Features

* **Targeted Stealth:** Hide any running application by simply typing its process name (e.g., `anydesk.exe`, `rustdesk.exe`)[cite: 1].
* **Simple & Intuitive Interface:** Clean GUI with straightforward **Start Stealth** and **Stop** controls[cite: 1].
* **Live Status Monitoring:** Clear status indicators (such as **Status: Ready**) to keep you informed of the utility's state[cite: 1].
* **Lightweight:** Built as minimal resource consumption and fast execution.

---

## 🚀 How to Use

1. Download the latest release of `DoQuietly.exe` from the [Releases page](../../releases).
2. Launch the application.
3. Enter the exact target executable name in the input field (e.g., `anydesk.exe`)[cite: 1].
4. Click **Start Stealth** to hide the app from your taskbar[cite: 1].
5. Click **Stop** whenever you want to deactivate the stealth mode[cite: 1].

---

## ⚠️ Note on Antivirus Warnings
Because DoQuietly has compiled independently, Windows Defender or other antivirus software may occasionally flag it with a false positive SmartScreen warning. You can safely bypass this by clicking **More info** -> **Run anyway**.
